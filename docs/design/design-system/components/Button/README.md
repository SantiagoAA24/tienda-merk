Botones de la app: principal lima (la acción de la pantalla), secundario, oscuro, de texto y de ícono.

Clases: `tem-btn` más una variante `tem-btn--primary`, `tem-btn--secondary`, `tem-btn--dark` o `tem-btn--text`; `tem-iconbtn` para el botón de ícono sobre verde.

**Qué aporta quien lo usa:** un `<button>` real con texto corto en infinitivo; para el de ícono, `aria-label`.

- Una sola `tem-btn--primary` por pantalla ("Nueva venta", "Cobrar"); ocupa todo el ancho y mide 68px.
- `tem-btn--dark` sirve para confirmar dentro de una barra lima (por ejemplo, "Cobrar" en la venta actual).
- `tem-btn--secondary` para acciones de apoyo ("Agregar producto"); `tem-btn--text` para enlaces como "Ver todos".
- Todos miden al menos 44px. No pongas texto lima sobre fondo claro ni botones de más de una línea.
